# 每日创作灵感 · 生成手册

> 让一个 AI agent 按这份说明，从你最近的笔记里长出「今天就能下手」的创作选题。
> 适合做内容/个人 IP 的人。换成你自己的平台与类别即可。

## 取数
- 看最近 1–2 周新归档的笔记主题（库里 / 或 `getnote notes --limit 25`）。
- 翻翻昨天的灵感清单，今天错开类别与平台、别重样。

## 生成尽量多灵感（多多益善 · 至少 6 条 · 每条独立可做）
素材足就尽量多给——**灵感越多越好，别自我设限封顶**。尽量覆盖更多内容类别与平台。每条给全：
- **钩子标题**（能让人停下来的那句）
- **一句话母题**（到底在讲什么）
- **3 点提纲**（今天就能照着录/写）
- **素材来源**（引用某条笔记，方便回看）
- **价值/转化角度**（这条服务于你的什么目标）

留至少一条「10 分钟能发」的轻选题，降低启动门槛。

## 平台与类别（换成你的）
- 平台示例：公众号 / 播客 / 小红书 / X / YouTube / 视频号
- 类别按你的内容支柱自定义（在 `config/categories.yaml` 里）

## 投递
写入库（如 `Ideas/每日灵感/<日期>.md`）；想手机看就存一条回 Get笔记。

## 口味
具体到「今天能动手」，不空泛、不鸡汤。
