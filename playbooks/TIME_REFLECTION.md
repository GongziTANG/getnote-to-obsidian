# 时间日记 · 生成手册（日 / 周 / 月反思）

> 让一个 AI agent 按这份说明，把你的笔记变成「时间账 + 反思日记」。两位先贤的精神：
> - **柳比歇夫**：量化时间账——时间花在哪、各类多少，诚实记录，先看清不评判。
> - **曾国藩**：每日反省——做了什么、有何得失、念头与改进，温和而诚实地照见自己。
> 换成你自己的风格即可（工作复盘 / 学习追踪 / 健身……）。

## 取数
1. 时间账：`python scripts/gn_timedata.py --day today`（周/月用 `--since X --until Y`）。
2. 当日新内容：看库里新归档的笔记主题、归档日志。

## 日报结构
```
# 🗓️ 时间日记 · {日期}

## 一、时间账（量化）
- 今日记录 N 条，总时长约 Xh；分类分布：A h · B h …
- 一句话画像：今天的重心在 ___

## 二、做了什么
- 3–6 条凝练今天真实发生的事（不流水账）

## 三、所思（向内自省）
- 看见：今天反复出现的念头/情绪/模式？
- 得：哪件事做得让自己满意？
- 失/省：哪里可以更好？
- 明日一念：给明天留一句提醒
```

## 周报 / 月报
在日报基础上加：**本周/本月主线** + **时间结构反思（各类配比是你想要的吗）** + 几个高光 + 想调整的 + 下一阶段意图。拉远一层，更结构化。

## 投递
写入库（如 `Journal/时间日记/<日期>.md`）。若你想在手机看，可顺手存一条回 Get笔记。

## 口味
量化部分只摆数字、不评判；反思部分温和诚实、向内、不鸡汤。短而有重量。
